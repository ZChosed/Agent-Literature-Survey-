# Papers to retrieve by hand

**4 papers** of the 84-document report corpus could not be downloaded automatically (open-access landing pages with no direct PDF link, or publisher bot blocks).

**How:** download each PDF and drop it in this folder (`manual_pdfs/`). Any filename works: each PDF is matched to its paper by the title on its first pages. Then run:

```bash
python fetch_documents.py --manual-only   # match, validate, extract; no network
python select_report_corpus.py            # refresh this checklist
```

A PDF that matches no paper, or two similar ones, is reported and left alone; rename it to the `paper_id` shown below to force the match. Matched PDFs still go through the same title-and-length check as a download, so a wrong file is rejected.

This file is regenerated by `select_report_corpus.py`; edits to it are overwritten.
